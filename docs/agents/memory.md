# Basic Memory 記錄

只記 repo 裡找不到的東西。`GLOSSARY.md`、ADR、Issues、PR 是事實來源，筆記放指標與摘要並連過去，不貼全文（分工見 [delivery.md](./delivery.md) 的「知識放哪裡」）。

## 位置

| 內容 | 資料夾 |
|---|---|
| org 層級（成員、權限、整體決策、模板演變） | `projects/Nasa-Hackathon-2026/` |
| 某個 repo | `projects/Nasa-Hackathon-2026/<repo 名>/` |

## 時機

| 情境 | 用 |
|---|---|
| 有替代方案與理由的決策 | `/basic-memory:bm-decide` |
| 收工或交接前 | `/basic-memory:bm-checkpoint` |
| 踩雷、環境設定、隨手記 | `/basic-memory:bm-remember` |

## 格式

- 標題用繁體中文，tags 用英文 kebab-case。
- 結尾放 `## 相關`，用 `[[標題]]` 連結；每個 repo 的第一篇筆記連回「NASA Hackathon 2026 GitHub org 初始化紀錄」。
- 帳密、token、API key 不寫進任何筆記。
